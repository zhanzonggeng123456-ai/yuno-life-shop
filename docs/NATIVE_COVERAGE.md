1. 当前 0.4.5 四组 Android 原生业务通过（69/75/33/24 秒）；保留 0.4.4 Android（65/76/33/24 秒）及各历史 iPhone 证据，不重复计算。
2. 新发现的问题必须有复现与修复验证；源码、构建包、实际安装版本分开记录。
3. 真实 iPhone 相机、相册与系统键盘结果未到，不能标记整个 App 最终验收完成。Android 物理真机暂无证据；任务说明允许模拟器/真机内部试用，因此将其单列为设备覆盖限制，不把模拟器称为真机。
4. 真实支付、物流、付费模型和应用商店发布明确不在本轮交付范围。不能以“整个 App”为由擅自启用这些外部服务。
