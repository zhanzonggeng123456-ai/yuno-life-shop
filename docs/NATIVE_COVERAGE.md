## 最终验收口径

1. 当前 0.4.5 四组 Android 原生业务通过（69/75/33/24 秒）；保留 0.4.4 Android（65/76/33/24 秒）及各历史 iPhone 证据，不重复计算。
2. 新发现的问题必须有复现与修复验证；源码、构建包、实际安装版本分开记录。
3. 2026-11-07 已补齐真实 iPhone 后置相机、相册 HEIF 来源导入及系统键盘，见 [硬件实测](NATIVE_HARDWARE_ACCEPTANCE.md)。本轮内部试用范围已闭环。Android 物理真机仍为覆盖限制，不把模拟器称为真机。
4. 真实支付、物流、付费模型和应用商店发布明确不在本轮交付范围。不能以“整个 App”为由擅自启用这些外部服务。

原始结果与版本见 [NATIVE_ACCEPTANCE.md](NATIVE_ACCEPTANCE.md)，启动和隔离测试方法见 [NATIVE_APP.md](NATIVE_APP.md)。
