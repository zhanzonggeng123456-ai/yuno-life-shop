# 0.5.0（14）：易用性与账号安全

2026-11-17，基于已分发的 0.4.8（13）实现。此文档记录源码候选的验证；最终部署、上传与审核状态单列于 TESTFLIGHT_DELIVERY.md。支付和配送继续模拟，没有接入付费服务。

## 用户可见变化

- 首次连接显示品牌与进度，超过 8 秒说明服务唤醒等待；连接失败可重试，高级地址设置折叠，窄屏与系统键盘下可滚动。
- 发布文字、属性、照片选择及未确认上传的请求标识保存到本机。照片复制到 App 持久目录，元数据使用安全存储，草稿按服务器和账号隔离。重开发布可恢复；可显式清除本机草稿，已上传草稿仍留在个人中心。再次分析前同步名称、描述和成色；上传失败后保留选图，显式重试使用同一请求标识，服务器去重创建/追加操作。替换照片失败时也保留待传文件。发布成功后清理本机草稿。标题与价格有就地错误提示并滚到对应字段。
- 订单、议价、配送、退款和争议详情说明状态与下一步，同时保留模拟提示。
- 账号安全可生成一次性恢复码：验证当前密码后仅显示一次，重新生成废弃旧码。邮箱+恢复码可重设密码，消费恢复码并撤销所有旧会话；没有接入邮件、短信或人工身份验证服务。必须在忘记密码之前保存恢复码。
- 删除账号需当前密码、输入 DELETE 和再次确认。服务端匿名化资料，撤销会话，删除草稿和本人消息正文，停止访问所属商品照片；必要交易、争议及审计记录保留，备份不保证即时清除。运行中识别任务未结束时拒绝删除，避免异步回写。服务端删除成功但本机清理失败时，明确区分两者并退出登录。
- 商品与消息可举报，运营页可查看并填写处理依据。认定成立后隐藏商品或移除消息正文；处理结果幂等。文本含少量明确违法词时拦截，不能替代完整的文本、图片审核及人工运营。
- 双向屏蔽隐藏对方商品，阻止新消息、购买、议价和拍卖操作；已有订单及审计仍可访问，账号安全中可解除。旧 v1 会话和商品读取同步执行相关限制。
- 隐私说明改为服务器保存商品与照片、本机保存草稿的实际情况。客服默认使用真实存在的 TestFlight 反馈入口；未擅自公开用户私人邮箱。运营可通过 YUNO_SUPPORT_EMAIL 配置公开支持邮箱。

## 深度性能与会话修复

- 商品列表、个人商品、关注和订单内嵌商品改为批量读取关联照片与卖家，避免每件商品发起两次数据库查询。测试中 12 件商品的关联查询由 24 次降至 2 次，结果与原接口逐字段一致；增加常用列表与反向屏蔽索引。未虚构公网耗时提升。
- 拍卖与关注在 SQL 中应用屏蔽规则；保留旧接口契约。原生 API 读取现在显式关闭数据库连接，避免依赖垃圾回收释放连接。缩略图限定解码尺寸，完整预览保留原图解码。
- 请求绑定账号会话版本：旧账号的延迟 401、资料或退出响应不能退出或覆盖新账号。安全存储写入按顺序执行；页面在身份切换时重新读取。
- 四组 iPhone 模拟器集成流程独立运行，新增发布页关闭后恢复草稿检查；仍将 fixture 选图与真实相机硬件结果区分。

## 验证与边界

- SQLite 后端：143 项通过（含安全、上传及批量读取回归）。日志 outputs/deep-optimization-backend.log。
- 官方 libSQL 本地驱动：143 项通过，日志 outputs/deep-optimization-backend-libsql.log；安全功能也在数据库照片模式验证，非真实 Turso 生产写入。
- Flutter 静态检查无问题，37 项组件/单元回归通过：见 outputs/deep-optimization-analyze.log、outputs/deep-optimization-flutter.log。草稿测试验证临时选图删除后持久照片仍可恢复、最新快照顺序、跨服务器/账号隔离和清理目录边界；账号删除、恢复表单、启动延迟与交易中日文说明均有测试。
- 本轮没有复用历史硬件结果声称已测新版本的相机/HEIF/系统键盘。仍需新候选实际设备烟测后记录结果。
- 新客户端依赖新增 /api/v2/account/*、/reports 和 /admin/reports 接口。发布顺序：通过 CI 后先备份并部署兼容后端，验证只读健康与接口，再签名和上传客户端。旧 v1/v2 与现有客户端保留兼容。
- 草稿照片依赖手机系统的 App 沙箱保护；安全存储不等于自行加密所有图片。已被他人下载或缓存的公开图片不能通过删号远程擦除。举报队列需要实际运营人员处理，不宣称全天候响应。
