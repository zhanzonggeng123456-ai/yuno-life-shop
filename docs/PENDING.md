## 用户在外部唯一真正必须办理的事项:真实收款商户签约

正式收款上线前,用户(平台经营者)须亲自完成,软件无法代办:

1. 选择日本持牌支付服务商(例如 Stripe Japan、PayPay、Paidy、
KOMOJU 等,须确认其支持市场平台分账与退款),提交商户开户申请。
2. 完成商户审查:提供经营者身份证明、银行账户、日本国内联系方式、
平台服务条款与退款政策等服务商要求的文件。
3. 取得商户号与 API 密钥(正式环境),在服务器环境变量中配置
YUNO_PAYMENT_PROVIDER=licensed 与 YUNO_PAYMENT_API_KEY。
4. 配置支付回调地址(服务商后台登记 Webhook URL),并用测试模式
跑通一笔支付、分账、退款全流程,核对分账明细与本系统
payment_intents 口径一致。
5. 完成分账与退款报备:确认佣金、运费代收、卖家结算周期与
退款责任划分符合服务商与日本法规要求;不得自行建立未经许可的
资金托管业务。
6. 切换正式收款后,在页面显著位置告知用户支付已改为真实扣款,
并保留模拟模式仅用于演示环境。

在完成上述步骤之前,平台只能用模拟支付做演示与本地测试,
不得对外宣称已实现真实收款。

## 本阶段明确不做的事

- 不做微服务集群与高成本云基础设施(模块化单体,保留扩展能力)。
- 不编造任何成交价、行情、AI 鉴定结论。
- 不承诺所有物品都能配送,不承诺回收所有商品。
- 不建立未经许可的资金托管业务。
