2026-11-07，按用户选择，以已验收 0.4.6 原生客户端统一代码，保留 main 的云存储、持久化部署、加密备份和恢复工具。由于新增协议选择与云兼容修复，候选版本为 **0.4.7（12）**。此前已安装 0.4.6 正常包及其历史证据保留，不把它改称合并版本通过。

## 兼容策略

- 原 `app/api.py` `/api/v1` 保持旧客户端响应格式。
- 新 `app/api_v2.py` `/api/v2` 保持 0.4.6 原生客户端的独立合同；客户端及对应测试改用 v2。
- 两个 API 共用原业务路由、数据库、会话和上传存储；新增原生草稿替换使用同一事务连接写入数据库照片存储。
- `mobile/` 统一为当前客户端。旧 0.2.2 客户端与模拟测试源码仍保留在 main 历史 `fb5d5e1`，相关 120 轮历史证据不变，不把其测试当作新版结果。
- 云端备份、部署配置、libSQL 驱动和旧 API 的测试保留。没有在本地测试中写入生产数据库、登录生产测试账号或关闭正常 8002。
